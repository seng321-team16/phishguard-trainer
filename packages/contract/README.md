# @phishguard/contract

TypeScript types generated from the API contract `api/openapi.yaml`.
The package contains declarations only (no runtime code), so `api` and `web` import it with `import type`.

| File | Content |
|---|---|
| `src/schema.d.ts` | Generated by `openapi-typescript`. Never edit by hand. |
| `src/index.d.ts` | Re-exports `paths`, `components`, `operations` and the shortcut `Schemas`. |

## Regenerate

Run this from the repository root after every change to `api/openapi.yaml` and commit the result:

```
npm run gen:contract
```

## Use

```ts
import type { Schemas } from '@phishguard/contract';

const body: Schemas['Health'] = { status: 'ok' };
```
